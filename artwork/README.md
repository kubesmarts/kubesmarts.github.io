# Kubesmarts Brand Assets

This folder contains all brand assets for the Kubesmarts project, including logos, mockups, and brand guidelines.

## Contents

- **logo/** - Various logo formats and variations
  - SVG versions for scalable use
  - PNG versions at different resolutions (2048px, 1024px)
  - Different variants: color, mono, horizontal, stacked, inverse, and icon versions

- **mockups/** - Brand mockups showing the logo in context
  - Website mockup
  - Social media template
  - Browser tab design
  - Business cards
  - Crewneck sweatshirt
  - Laptop stickers
  - Booklet layout

- **brand.json** - Brand configuration and color specifications

- **kubesmarts-brand-book.pdf** - Complete brand guidelines and specifications

- **kubesmarts-brand-board.png** - Brand board visual reference

## Using These Assets

The logo and all brand assets were created using **Recraft**. If you need to create variations or expand upon these designs, you can upload the logo files to Recraft to continue editing and customizing them.

## Recommended Usage

- Use SVG versions for web and digital applications (they scale infinitely)
- Use PNG versions for raster-based designs or when SVG support isn't available
- Refer to the brand guidelines PDF for color codes, spacing, and proper logo usage
- Check the brand.json file for specific color values and design system specifications
